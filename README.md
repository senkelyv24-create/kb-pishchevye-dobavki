# База знаний по пищевым добавкам

Прототип курсового проекта: поиск по фактам приложения 2 ТР ТС 029/2012 и проверка состава правилами. Факты и правила лежат в SQLite, поиск и вывод выполняются запросами SQL.

Запуск из этой папки:

```
python -m pip install -r requirements.txt
python app.py
```

После запуска открыть http://127.0.0.1:5000

Проверка правил:

```
python -m unittest tests.test_engine
```

Схема — `sql/schema.sql`, наполнение — `sql/seed.sql`, запросы поиска и правил — `sql/scored.sql` и `sql/consult.sql`. Черновики фактов лежат в `data/*.json`: после правки их снова собирают в SQL командой `python tools/build_db.py`. Поиск понимает латинскую и русскую «Е» в индексе, а также бытовые имена вроде «сода», «глутамат», «стевия».

Пояснительная записка: `docs/Курсовой_проект_Сенкель_БЗ_пищевые_добавки.docx`. Текст доклада: `docs/Доклад_Сенкель_БЗ_пищевые_добавки.docx`.
