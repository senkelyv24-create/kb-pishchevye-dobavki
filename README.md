# База знаний по пищевым добавкам

Прототип курсового проекта: поиск по фактам приложения 2 ТР ТС 029/2012 и проверка состава правилами.

Запуск из этой папки:

```
python -m pip install -r requirements.txt
python app.py
```

После запуска открыть http://127.0.0.1:5000

Проверка правил:

```
python -m unittest tests.test_engine
```

Факты лежат в `data/additives.json`, правила — в `data/rules.json`. Поиск понимает латинскую и русскую «Е» в индексе, а также бытовые имена вроде «сода», «глутамат», «стевия».

Пояснительная записка: `docs/Курсовой_проект_Сенкель_БЗ_пищевые_добавки.docx`. Текст доклада: `docs/Доклад_Сенкель_БЗ_пищевые_добавки.docx`.

Чтобы выложить код на GitHub, в этой папке после входа в GitHub:

```
git add .
git commit -m "Прототип базы знаний по пищевым добавкам"
gh repo create kb-pishchevye-dobavki --public --source=. --push
```

Полученную ссылку нужно вписать в главу 3 записки, в строку «Ссылка на проект в Git».
